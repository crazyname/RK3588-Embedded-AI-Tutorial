## 学习目标

- 掌握分类模型在板端的预处理与后处理
- 通过 CMake 构建并运行示例
- 分析模型输入输出张量和 top-k 分类结果

## 核心原理与工程设计

### MobileNet 是怎样的小型分类网络

MobileNet 系列面向移动端与嵌入式设备，其中 Depthwise Separable Convolution 将普通卷积分解为逐通道空间卷积和通道混合点卷积，常能显著减少计算量。输入通常是固定尺寸的 RGB 图像，输出是分类 logits 或 scores。具体输入尺寸、预处理和类别数应查模型文件与训练定义。

**理解检查：** 能说明 Depthwise 与 Pointwise 作用以及为什么它们能减算量。

### 分类前处理与标签协议

训练侧的 resize/crop、RGB、mean/std 和 tensor layout 必须在 RK3588 上等价实现。模型输出值的大小可用于选取 top-k，但不等于‘任意最大索引对应你想象的类别’。标准 ImageNet 可能使用 1000 个类别，标签文件仍必须与具体训练模型一一对应。

**理解检查：** 一个完整结果包含类别索引、标签来源、分数及对应原图。

### 先 Python 再 C++

按 Model Zoo 自带的 MobileNet 示例做 PyTorch/ONNX/RKNN 的结果比对，再在板端执行官方 Python/C++ 推理。较好的自学顺序是：固定样例图→输出 shape 与 top-k→替换本地图片→用不同前处理验证错误。

**理解检查：** 确保输入图像原始文件和预处理后 tensor 可复用到后续封装课程。

## 动手实验

### 实验 1：获取官方样例

选择 RKNN Model Zoo 的 MobileNet 目录，记录模型文件、输入 shape、对应 label 列表。

**完成证据：** 保证模型和示例后处理来自同一仓库版本。

### 实验 2：输出 top-5

使用官方示例在可用板端加载模型，打印五个最高分数对应的索引与标签。

**完成证据：** 保存原图、tensor 属性和 top-5 结果。

### 实验 3：变换输入验证

分别尝试正确 RGB 和错误 BGR（仅用于对照），观察同图分类输出差异。

**完成证据：** 解释为什么通道错误可能影响分类，实验后恢复正确配置。

## 排错技巧

### 分类最高分不对应真实物体

- 根因：输入归一化、颜色或 labels 顺序错误。
- 如何核对：核对模型官方前处理与标签索引，复用固定测试图。

### MobileNet 明明小但 FPS 不高

- 根因：CPU 图片解码或复制占比高、频率/运行库不匹配。
- 如何核对：分别测模型推理与完整文件输入到分类输出的耗时。

## 工程案例

**情境：** MobileNet 输出的索引 283 被程序打印为‘狗’，但同版本标签表指向其他类别。是否要重新训练模型？

**分析过程：** 先检查 label 列表是否为模型专用、是否存在从 0 还是从 1 开始的偏移，再看输出 shape 和前处理。很多此类问题不需要重新训练。

**提交证据：** 模型来源、标签文件来源、索引映射与输出数值。
