# 第17讲｜模型剪枝

> 正确理解 SDK 自动剪枝与训练期模型剪枝的区别。

**单元：** 模型转换与优化　｜　**硬件：** RK3588

## 学习目标

- 解释剪枝降低模型体积与计算量的原理
- 认识自动无损剪枝的适用边界
- 对剪枝结果进行精度、速度和内存复测

## 核心知识

剪枝通过删除冗余权重、通道或计算路径来降低资源占用。课程介绍 RKNN-Toolkit2 在某些版本提供的自动剪枝能力，着重于可无损移除的冗余计算。它与深度学习训练阶段的结构化剪枝/微调不同，并非所有网络都存在足够冗余可以优化。是否启用相应配置应查对当前 SDK 版本文档，而不是直接按口播转写猜测参数名称。

## 实验与实践步骤

1. 记录原始模型的权重大小、任务精度、NPU 延迟和内存
2. 核对当前 SDK 的剪枝开关、条件与支持的模型结构
3. 启用自动剪枝并保留构建日志
4. 比较剪枝前后模型大小、运算量和端到端性能
5. 若收益过低，分析模型结构是否具备可裁剪冗余

## 验收标准

- [ ] 能说明剪枝成功和性能加速并非同义词
- [ ] 能以一致的验证集检查精度是否变化

## 常见问题与注意事项

- 没有剪枝日志不一定意味着转换失败
- 不能把自动无损剪枝等同于手工结构化剪枝训练

## 课后练习

1. 设计一份对照实验表，记录剪枝前后模型大小与精度
