## 学习目标

- 说明嵌入式 AI 学习路径
- 区分训练、转换和推理
- 列出自己的实验环境

## 核心知识

课程以 RK3588 为实践平台，帮助嵌入式开发者、算法学习者从基础认知进入模型部署。学习主线是：硬件与 NPU → 工具链和环境 → 模型转换/评估 → C/C++ 板端部署 → YOLO 优化与大模型。课程视频提及的代码包、网盘文件并不等于仓库已经包含了这些资料。

## 实践步骤

1. 确认开发板型号、系统版本、内存和接口
2. 准备 Ubuntu 开发主机与板端终端连接
3. 建立学习记录，保存命令、环境版本、日志和截图
4. 先通过分类模型完成最小闭环，再开展目标检测和大模型实践

## 完成标准

- [ ] 能解释训练模型、ONNX、RKNN 与板端推理的关系
- [ ] 记录个人开发环境清单
