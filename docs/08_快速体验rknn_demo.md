## 学习目标

- 定位 RKNN 官方 examples 与测试资源
- 在主机验证示例模型
- 在板端执行 NPU 推理并检查结果

## 核心知识

本讲先运行现有官方示例，再学习自己写转换和推理代码。PC 端可以使用模型转换示例或模拟器快速检查模型输入输出；RK3588 板端运行则真正涉及 NPU 驱动和用户态运行时。建议始终保留测试图片、模型版本、返回值及日志。

## 实践步骤

1. 选择和正在使用的 SDK release 匹配的官方 demo
2. 核对测试图片、源模型/RKNN 模型和依赖库的路径
3. 在 Ubuntu 主机执行官方文档提供的对应示例
4. 将板端程序、模型和测试数据复制到开发板
5. 在板端运行并比对识别输出与输入内容

## 完成标准

- [ ] 能说明模拟器与真实 NPU 推理区别
- [ ] 同一测试输入有合理的分类或检测结果

## 注意事项

- 不同 SDK 版本的 `examples` 路径及脚本名称可能不同
- 避免把没有真正运行的模拟器结果当作板端测量值

## 课后练习
