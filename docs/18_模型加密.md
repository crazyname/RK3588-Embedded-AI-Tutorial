# 第18讲｜模型加密

> 学习 RKNN 模型加密与平台适配。

## 学习目标

- 理解加密模型的用途和限制
- 核对加密 API 的芯片/SDK 支持条件
- 完成加密前后推理验证

## 核心知识

模型加密可提高部署模型结构和权重的保密性，但无法替代完整的访问控制、密钥保管和系统加固。课程提到加密等级与不同芯片支持差异，并强调加密后的模型必须与目标平台、SDK 和运行时能力匹配。加密 API 的名称、等级及参数应查当前 SDK 手册。

## 实验与实践步骤

1. 备份原始 `.rknn` 文件并记录 hash
2. 确认 RK3588 及所用运行时支持模型加密
3. 按 SDK 对应示例生成加密模型文件
4. 在同一板卡分别加载原始和加密模型，检查推理成功与输出
5. 测试不支持平台或错误版本时的异常处理

## 验收标准

- [ ] 加密模型在目标板能正常推理
- [ ] 有明确的模型版本和安全存储方案

## 常见问题与注意事项

- 不能将加密等级理解为不可破解的安全承诺
- 不支持的板卡或运行库可能无法运行加密后的模型

## 课后练习
