## 学习目标

- 了解权重与中间特征的内存组成
- 使用 SDK 内存评估接口
- 区分模型文件大小和进程真实内存

## 核心知识

模型文件在磁盘上的大小不等于推理时的实际内存。评估可能包含模型权重（weight memory）、中间 tensor（internal memory）与其他（other memory）等分类。板端还需要图像输入输出缓冲、应用程序、运行时句柄及系统服务。课程介绍 `eval_memory` 一类工具，在某些 SDK 版本中需在初始化运行时开启内存评估选项。

## 实验与实践步骤

1. 加载一个已经验证可正常推理的 `.rknn` 模型
2. 核对当前 Toolkit2 是否要求在 `init_runtime` 中开启内存评估开关
3. 运行内存评估并保存 weight/internal/other/total 输出
4. 使用系统内存观测手段检查整个应用进程
5. 估算多实例、多路视频增加的缓存和上下文开销

## 验收标准

- [ ] 能说明模型文件、NPU 内存和进程 RSS 的区别
- [ ] 能记录同一模型多种输入尺寸的内存变化

## 常见问题与注意事项

- 运行时内存统计不一定涵盖应用全部内存
- 不同比特宽度、批量和输入形状会改变内存要求
