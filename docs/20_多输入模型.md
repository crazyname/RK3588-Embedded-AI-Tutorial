## 学习目标

- 区分多输入、多 Batch 与动态 shape
- 识别模型各输入端口及其类型
- 确保输入顺序、尺寸和预处理正确

## 核心知识

多输入模型在一次推理中需要不同来源或语义的数据，例如图像加元数据、双目图像或多传感器特征；多 Batch 则主要让同构样本一起处理。不同输入端口可能有不同的 shape、dtype 或归一化要求。模型结构应通过 Netron、ONNX metadata 或运行时 `query` 接口核对。

## 实验与实践步骤

1. 用 Netron 列出模型全部输入名称、形状、布局和数据类型
2. 分别构造每个端口的测试张量
3. 按照 API 规定的索引顺序传入输入列表
4. 执行推理并验证输出个数与参考框架一致
5. 记录各输入数据以方便重现异常结果

## 验收标准

- [ ] 能解释每个输入端口的用途和顺序
- [ ] 能验证输入列表与模型声明完全一致

## 常见问题与注意事项

- 多个输入端口不是把图像直接当作 batch 拼接
- 不要默认所有输入共享均值、标准差或布局
