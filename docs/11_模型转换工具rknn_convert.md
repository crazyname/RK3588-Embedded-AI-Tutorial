## 核心知识

`rknn_convert` 是相关 SDK 提供的命令行转换工具，可通过配置文件组织源模型、目标平台、输入信息及量化选项。它与 Python API 的核心目标类似，适合批量转换或持续集成。由于 CLI 参数和 YAML 键名会随工具链版本变化，本讲不凭口播字幕猜测完整命令，实际应使用该版本自带 `--help` 与示例。

## 实践步骤

1. 查找当前 RKNN SDK 附带的转换工具和示例 YAML
2. 读取 `--help`，确定参数和配置文件位置
3. 复制官方示例，替换模型文件与输出路径
4. 运行 CLI 并检查退出状态、转换日志和输出模型
5. 使用已知测试输入比较 Python API 和 CLI 导出的模型
