# RK3588 嵌入式 AI：12 周自学指南

本系列按 35 节独立课程组织，HTML 是上下滚动阅读的互动版，MD 是可以检索、做笔记的文字版。原视频字幕只保留在 MD 文末作溯源。

## 自学必备条件

建议先掌握 Linux 终端、Python 虚拟环境、NumPy 数组、C/C++ 基础和卷积网络常用术语。准备 RK3588 开发板、稳定电源/散热、串口或网络、匹配 BSP 的固件、NPU 驱动与 Runtime，以及适合 Toolkit2 的 x86_64 Linux 主机。尚无板卡也可以先学理论、ONNX 检查和模拟环境，但不能把模拟结果当硬件性能。

## 一节课要如何学

1. 先读场景，写下自己的假设；不要立即展开答案。
2. 逐条解释三个原理专题；将每个概念改写为‘输入、动作、输出、限制’。
3. 完成三个实验任务，保存截图、日志或计算过程。没有真实板卡时将‘仅模拟’明确标注。
4. 尝试改变一个变量，观察 RGB/BGR、shape、量化或后处理阈值造成的影响。
5. 独立回答课堂测验和案例题，再核对结论。
6. 在学习日志中记录软硬件、模型文件哈希、输入、预期与实际结果。

## 分阶段必考能力

- 能画出：训练/ONNX → Toolkit2 → .rknn → Runtime → NPU Driver → NPU。
- 能识别：shape、dtype、layout、RGB/BGR、mean/std、batch、多输入之间的区别。
- 能比较：源框架、ONNX Runtime、RKNN 非量化与 INT8 在相同输入上的结果。
- 能完整解释：C API 的 rknn_init、query、inputs_set、run、outputs_get、outputs_release 和 destroy 的生命周期。
- 能手算：letterbox 的 scale/pad 逆变换，理解 NMS 和 IoU。
- 能测量：NPU 推理时间、端到端延迟、FPS、p95、峰值内存和热节流。

## 推荐毕业实训：RK3588 实时安全帽检测

先用官方已验证的 YOLOv5 或 YOLOv8 模型完成图片检测，再实现摄像头推理、C++ 封装和日志；进阶版再训练自己的安全帽/人员数据集，逐阶段验证 PyTorch、ONNX、RKNN 的数值与 mAP。报告中同时给出错误案例、转换配置、编译环境、内存与 FPS。YOLO26 的导出/目标板兼容性需要具体验证，不能仅凭 ONNX 能导出就宣称 NPU 可运行。

## 不可忽略的安全与真实性

任何驱动/系统更新前，应核对板卡 BSP 和恢复方案。不要随便刷写未知来源的 ko/dtb 镜像。未经真实 RK3588 测试的命令和优化成果应标记为‘示例或待验证’，不得虚构性能结果。模型与数据遵守各自许可，实验脚本避免把生产密钥或隐私数据提交到公共仓库。
