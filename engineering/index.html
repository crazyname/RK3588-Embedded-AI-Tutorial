RK3588 工程实验与源码验收总览

共 17 项工程，全部采用一张长页上下阅读。每个模块均标明源码、实验 MD、测试入口与验收方式；实际硬件状态以真实板端日志为准。

本页面由工程清单整理，静态离线可打开；任何离线测试通过都不构成 NPU、RGA 或摄像头已在真实 ROCK 5B 验收的声明。

C++ YOLOv8 性能对照11. RKLLM 原生 C API 流式生成12. RKLLM 多次推理统计13. RKLLM 模型与提示词完整性14. ONNX 基准模型与部署转换15. 官方 YOLOv8 基线与 ONNX 导出16. RKNPU2 C++ 分类和输入绑定对照17. RKNPU2 C++ 张量绑定与零拷贝边界
